# Ticket 16: Regex and Color workspace redesign

Regex and Color Conversion now use the approved compact Workbench content treatment, stable identities for every action Button, and generic sofui `SelectableList` plus `ConfirmationBar` for History. The app still owns History policy, retained-entry checks, confirmation, exact restore and Clipboard writes. Both modules dropped their `HistoryPanel` and dynamic-label Button compatibility calls.

Regex retains six independent boolean flag controls; a single-selection control would change their meaning. Its named Rust engine/dialect, flags and replacement guidance, match/capture list, preview and refusal diagnostics remain visible. The ticket-05 worker, one-running/one-pending bound, cancellation, revision checks, idle poller and resource limits were not changed. Color retains its synchronized source/swatch/channel/output model, four `NumericStepper` channels, explicit Convert/Paste/Clear and per-representation Copy. Neither Utility gains a new regex dialect or color space.

The retained ticket-05 deterministic worker tests cover one running/one latest pending request, unread completion poller liveness, stale publication rejection, and clear/restore invalidation. The retained ticket-06 GPUI test covers consecutive channel adjustments, pre-settlement Copy agreement, single settled recording, and invalid-text Copy refusal. Ticket 16 adds a GPUI Regex keyboard/focus test for flag selection, History list selection and confirmed exact restore without re-execution or duplicate recording. The Color GPUI test now also selects a retained row through the generic list, confirms restore through the generic bar, and checks source/output agreement and unchanged History count.

A focused Color restore check exposed a shared History edge: `record()` returned the in-memory `serde_json::Value`, which can differ from its persisted representation for floating-point payloads. The exact-entry guard then rejected an entry that had just been recorded. Coordinator-authorized `history.rs` now returns the canonical entries parsed from the bytes actually written, while preserving atomic replacement, write failure and paused-recording behavior. A new store-to-view regression verifies the returned Color-like float entry equals the later load and remains restorable.

Scoped `rustfmt --edition 2021` passes for the three touched source files. Offline Cargo with `CARGO_TARGET_DIR=/private/tmp/sofdevtool-terra-target` passes: 19 History tests, 8 Regex tests, 1 Color GPUI test, and `cargo clippy -p sofdevtool-app --lib -- -D warnings`. The Color test initially failed at its restore confirmation because the retained-entry guard rejected the newly recorded float payload; it passes with the shared persistence fix. The first combined Regex run had two transient failures, but each test passed alone and the full eight-test Regex group passed on two subsequent runs. The coordinator owns the final frozen combined gate. No native-runtime claim is made from these automated tests.
