# Rust-only SofDevTool and sofui

This is the separate planning package for completing the Rust application, preparing sofui for later independent release, and retiring the Swift implementation.

- [Complete specification](spec.md): agreed product scope, the six review findings, architecture, testing and delivery contract.
- [Approved ticket index](ticket-proposal.md): 22 published tickets with blocking edges and story coverage. Each linked ticket contains its accepted criteria and testing guidance.
- [Project tracker conventions](../../docs/agents/issue-tracker.md): local Markdown and triage vocabulary.

The current assignment is documentation only. No implementation, native preview, installation, commit or remote publication is part of preparing this package.

## Publication and execution boundaries

The owner approved the 22-ticket breakdown on 2026-09-22. All tickets are now published as individual Markdown files under this initiative's `issues` directory, numbered from 01 in dependency order and labelled `ready-for-agent`. Approval and publication cover documentation only; no ticket is claimed or implemented.

Ticket triage and scheduling are separate. `ready-for-agent` means eligible after its recorded blockers are accepted; it does not override the current documentation-only assignment. The future native preview also needs owner approval before full visual rollout.

The old migration's tickets 01–22 remain unchanged historical records. Numbers in the new index refer only to this initiative. The former follow-up specification 23 was moved here at the owner's request; there is one canonical copy.

The specification owns product behavior. Individual ticket bodies own status, acceptance criteria and blocking edges. The approved index retains the publication approval and navigation links, using its original filename to preserve references. The parent specification's content and status are unchanged by publication.
