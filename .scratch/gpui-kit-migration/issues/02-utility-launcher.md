# 02: Utility Launcher with kit controls

**What to build:** Search, navigate and open Utilities with standard kit controls while preserving Launcher shortcuts and application/window activation.

**Blocked by:** 01: Workbench and official Catppuccin themes

**Status:** ready-for-agent

**Type:** task

- [ ] All registered Utilities remain searchable and open the correct workspace.
- [ ] Keyboard navigation, selection, dismissal and focus use supported kit interactions.
- [ ] Existing shortcut configuration and activation behavior are preserved; global hook ownership remains in the app.
- [ ] Theme changes apply to the Launcher; no sofui controls or custom palette remain in this surface.
- [ ] Exercise search/open/dismiss through app interaction checks and record native activation evidence separately.

## Delivery constraint

Part of one atomic integration effort. This work package is verifiable by its scenarios but is not an independently accepted or shipped intermediate product. Only the final integrated tree is promised green. No compatibility wrappers or expand-contract rollout are authorized.
